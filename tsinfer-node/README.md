## TSINFER-NODE

`Tsinfer-node` is a reimplemented version of `tsinfer`, which is presented in the following paper:

- Kristensen, Erik Krogh, and Anders Møller. "Inference and evolution of typescript declaration files." Fundamental Approaches to Software Engineering: 20th International Conference, FASE 2017, Held as Part of the European Joint Conferences on Theory and Practice of Software, ETAPS 2017, Uppsala, Sweden, April 22-29, 2017, Proceedings 20. Springer Berlin Heidelberg, 2017.


We reimplement `tsinfer` in JavaScript and support Node.js platform.
